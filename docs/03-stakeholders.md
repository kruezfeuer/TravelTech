# Участники системы

## Карта участников

| Участник | Роль | Цель |
|---|---|---|
| Путешественник | Основной пользователь | Спланировать поездку и получать актуальные изменения |
| Участник группы | Соавтор плана | Видеть и согласовывать изменения маршрута |
| Сервис планирования путешествий | Основная система | Объединять все элементы поездки и управлять ими |
| Flight API | Внешний поставщик | Передавать статусы рейсов и изменения |
| Hotel API | Внешний поставщик | Предоставлять проживание и подтверждение брони |
| Transfer API | Внешний поставщик | Предоставлять трансферы и их статусы |
| Activity API | Внешний поставщик | Предоставлять активности и бронирования |
| Notification Service | Инфраструктурный сервис | Доставлять уведомления о событиях |
| Recommendation Engine | Инфраструктурный сервис | Формировать персональные предложения |
| Служба поддержки | Оператор | Разбирать обращения по поездкам и бронированиям |

---

## Путешественник

Потребности:

- видеть единый план поездки;
- быстро понимать, что изменилось;
- получать предложения без ручного поиска;
- синхронизировать изменения с группой;
- работать с офлайн-доступом.

---

## Участник группы

Потребности:

- видеть общий маршрут;
- согласовывать изменения;
- понимать влияние изменения рейса на всю поездку;
- не терять изменения при отсутствии связи.

---

## Сервис планирования путешествий

Ответственность:

- хранить структуру поездки;
- управлять бронированиями и событиями;
- обрабатывать статусы рейсов;
- пересчитывать маршрут;
- синхронизировать изменения;
- управлять сроками хранения данных.

---

## Внешние поставщики

Потребности:

- получать корректные запросы;
- возвращать актуальные статусы и доступность;
- минимизировать дублирование запросов;
- соблюдать договорённые форматы данных.

---

## Служба поддержки

Потребности:

- видеть историю изменений;
- понимать источник проблемы;
- находить конкретное бронирование или изменение статуса;
- видеть текущее состояние поездки.
