# Ошибки

## 1. Назначение документа

Документ описывает типовые ошибки и способ их обработки в сервисе планирования путешествий.

---

## 2. Формат ошибки

```json
{
  "error": {
    "code": "EXTERNAL_API_UNAVAILABLE",
    "message": "Внешний сервис временно недоступен",
    "details": [],
    "requestId": "8ecb8a7c-9f2f-4e0f-a232-4ac3d6ed7cf0",
    "timestamp": "2026-11-02T10:10:00Z"
  }
}
```

---

## 3. Справочник ошибок

| HTTP | code | Ситуация | Поведение |
|---|---|---|---|
| 400 | `INVALID_REQUEST` | Некорректный формат запроса | Вернуть ошибку валидации |
| 401 | `UNAUTHORIZED` | Отсутствует авторизация | Запретить доступ |
| 403 | `FORBIDDEN` | Недостаточно прав | Запретить действие |
| 404 | `NOT_FOUND` | Сущность не найдена | Сообщить об отсутствии |
| 409 | `CONFLICT` | Конфликт версий или правок | Попросить повторить или выбрать вариант |
| 422 | `UNPROCESSABLE_ENTITY` | Нарушены бизнес-правила | Возвратить причину отказа |
| 429 | `TOO_MANY_REQUESTS` | Превышен лимит | Ограничить повторные обращения |
| 500 | `INTERNAL_ERROR` | Внутренняя ошибка | Логировать и вернуть общий ответ |
| 503 | `EXTERNAL_API_UNAVAILABLE` | Внешний сервис недоступен | Деградировать функциональность |

---

## 4. Типовые ошибки по домену

### 4.1. Недоступен Flight API

**Ситуация:** сервис не может получить статус рейса или альтернативы.  
**Поведение:** показать пользователю, что данные временно недоступны, сохранить попытку повторного запроса.

### 4.2. Задержка данных о рейсе

**Ситуация:** внешний источник передаёт изменения с опозданием.  
**Поведение:** пометить данные как потенциально неактуальные и отложить финальное обновление маршрута.

### 4.3. Конфликт правок между участниками

**Ситуация:** два участника изменили один и тот же план.  
**Поведение:** сохранить конфликт и показать пользователю обе версии для выбора.

### 4.4. Несоответствие визовым ограничениям

**Ситуация:** предложенная альтернатива требует визы, которой нет.  
**Поведение:** исключить вариант из рекомендаций.

### 4.5. Несоответствие по багажу

**Ситуация:** у альтернативного рейса другой багажный лимит.  
**Поведение:** пометить ограничение и не предлагать вариант, если оно критично.

### 4.6. Офлайн-режим

**Ситуация:** пользователь вносит изменения без связи.  
**Поведение:** сохранить локальные изменения и синхронизировать позже.

### 4.7. Истёк срок хранения паспортных данных

**Ситуация:** срок использования данных завершён.  
**Поведение:** удалить или обезличить записи и запретить дальнейшее использование.
