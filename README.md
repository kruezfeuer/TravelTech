# TravelTech: сервис планирования путешествий

Портфолио-кейс системного аналитика для сервиса, который помогает планировать поездку, отслеживать изменения рейсов и синхронизировать маршрут с участниками поездки.

## Что демонстрирует кейс

- формализацию проблемы и границ системы;
- моделирование бизнес-процессов;
- работу с групповым режимом;
- обработку задержек и отмен рейсов;
- предложения альтернатив;
- учёт офлайна, тайм-зон и ограничений по данным;
- проектирование API, модели данных и статусов.

## Ключевая идея

Сервис объединяет перелёты, проживание, трансферы и активности в единый план поездки. Если внешний источник сообщает о задержке или отмене рейса, система уведомляет пользователя и предлагает альтернативы с учётом багажа, визовых ограничений, тайм-зон и уже забронированных элементов поездки.

## Примечание

Документы созданы как учебный портфолио-кейс и не описывают реальный внутренний сервис конкретной компании.
